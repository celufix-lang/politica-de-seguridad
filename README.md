# politica-de-seguridad
**Servicio Técnico Celulares** gestiona órdenes de reparación para talleres móviles. Permite registrar clientes, equipos (modelo, IMEI), fallas, presupuestos y claves o patrón 3x3. Ofrece seguimiento por estados (Ingresado, En revisión, Listo, Entregado), búsqueda rápida, base de datos local offline y sincronización con la PC vía QR y Wi-Fi.
